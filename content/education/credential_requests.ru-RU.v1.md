# Секреты остаются у владельца

Не сообщайте пароль, код подтверждения, полный номер карты и защитный код. Не вводите эти данные по ссылке из сообщения.

## Если данные уже переданы

Самостоятельно откройте официальное приложение банка и используйте доступный там канал поддержки.
