# Альфа Защита

Проект системы раннего предупреждения о финансовом мошенничестве: анализ подозрительных коммуникаций и ресурсов, объяснение риска и защита перевода.

Текущий этап — фундамент P01–P04: воспроизводимая среда, общие типы и границы слоев,
SQLite/in-memory UnitOfWork, технические гарантии idempotency/audit/outbox и исполняемый
HTTP-контур. Сейчас доступны только health endpoints; бизнес-возможностей и web-интерфейса
пока нет. Readiness намеренно возвращает 503 до появления обязательного каталога P07.
