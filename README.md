# Альфа Защита

Проект системы раннего предупреждения о финансовом мошенничестве: анализ подозрительных коммуникаций и ресурсов, объяснение риска и защита перевода.

Текущий этап — архитектура, каталоговый каркас и фундамент P01–P03: зависимости, общие типы,
исполнимые границы слоев, SQLite/in-memory UnitOfWork и технические гарантии
idempotency/audit/outbox. HTTP-приложения пока нет — его собирает P04.
