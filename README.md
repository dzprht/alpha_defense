# Альфа Защита

Проект системы раннего предупреждения о финансовом мошенничестве: анализ подозрительных коммуникаций и ресурсов, объяснение риска и защита перевода.

Текущий этап — P01–P10: воспроизводимая среда, границы слоев, SQLite/in-memory
UnitOfWork, технические гарантии idempotency/audit/outbox, HTTP-контур и
синтетические demo-сессии. Backend создает и восстанавливает сессию, изолированный
namespace и явные согласия; клиент не может выбрать себе роль. Web-shell показывает русский
onboarding, восстанавливает серверную сессию и изменяет согласия через защищенные команды.
Версионированный синтетический каталог S01 проходит JSON Schema, проверку hash, версий и
внутренних ссылок; при валидной БД и каталоге readiness возвращает 200. Реестр угроз
атомарно публикует проверенные снимки и различает активное точное совпадение, отсутствие
совпадения и недоступность данных. Внутренняя граница приема коммуникаций хранит неизменяемые
наблюдения SMS, мессенджера, расшифровки звонка и web-ресурса, отделяет raw-content от
нормализованных телефонов/URL/доменов и дедуплицирует source event только внутри
namespace. Внутренний workflow атомарно связывает новое наблюдение с предварительным
инцидентом, повышает версию контекста и оставляет namespace в состоянии незавершенного
анализа; временная близость сама по себе не объединяет контакты. Публичного
`POST /observations`, оценки риска и продуктовых экранов пока нет.
